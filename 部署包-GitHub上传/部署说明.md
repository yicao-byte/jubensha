# AI 主持代理服务端（三选一）

DeepSeek 官方接口不支持浏览器直连（CORS），需要一个轻量服务端把请求转发给 DeepSeek，API Key 只存在服务端环境变量里。

## 方案一：Render（推荐，免费）

1. 打开 [render.com](https://render.com) 用 GitHub 免费注册。
2. 点 **New → Web Service**，选择包含本文件夹的仓库（`server.js` 在根目录）。
3. 构建命令留空或填 `echo ok`，启动命令填 `node server.js`。
4. 在 **Environment** 添加 `DEEPSEEK_API_KEY` = 你的 DeepSeek Key，保存并 Deploy。
5. 得到 `https://xxxx.onrender.com` 后，把它填进游戏「⚙ 设置 → 代理地址」，或直接访问它打开游戏（会自动同源代理，无需手填）。

也可以直接把本文件夹推到一个 GitHub 仓库，用仓库里附带的 `render.yaml` 一键创建服务。

## 方案二：Cloudflare Workers（免费）

1. 打开 [dash.cloudflare.com](https://dash.cloudflare.com) 注册并进入 **Workers & Pages**。
2. 新建 Worker，把 `worker.js` 内容粘贴进去。
3. Settings → Variables 添加 `DEEPSEEK_API_KEY`，保存并部署。
4. 得到 `https://你的worker名.workers.dev`，在游戏「⚙ 设置 → 代理地址」填这个地址（网页本身可放任意静态托管，如 Netlify Drop）。

## 方案三：本地/任意 Node 服务器

```bash
DEEPSEEK_API_KEY=sk-xxxx node server.js
```

把 `野狗不需要墓碑.html` 复制为 `public/index.html`，浏览器打开 `http://localhost:3000` 即可。要用公网访问，可把该服务部署到任意 Node 云主机。

> 安全提示：`server.js` 不会把 Key 发给浏览器；浏览器只请求 `/api/chat`，由服务端注入 Authorization 头。
